# Мой транспорт — TimeTransport
Целевая платформа - Android

[![Скачать APK](https://img.shields.io/badge/Android-Скачать_APK-3DDC84?style=for-the-badge&logo=android&logoColor=white)](https://github.com/m0ps3k/TimeTransport/releases/latest/download/TimeTransport.apk)

Приложение для просмотра расписания автобусов Санкт-Петербурга и окрестностей. Показывает время до отправления в минутах для выбранного направления и остановки.

## Возможности

- Переключение направлений «Туда» и «Обратно».
- Выбор остановки для обратного направления.
- Отдельные расписания для будней и выходных.
- Карточки недавних, текущих и ближайших отправлений.
- Поддержка маршрутов **119, 285, 4, 8 и 476**.
- Автоопределение направления исходя из системного времени, а также автоматическое уточнение остановки отправления (согласно времени до 20 включительно - м. Ломоносовская, после - Володарский мост)

Время рассчитывается по локальному расписанию, а не по фактическому положению автобусов. Данные находятся в `TimeTransport/TimeTransport/Data/timetable.json` и встраиваются в приложение при сборке; изменение расписания требует пересборки.

## Технологии и структура

Проект использует **C#, .NET 10, Avalonia UI и CommunityToolkit.Mvvm**. Интерфейс организован по MVVM: представления, модели представления и сервис загрузки расписания разделены.

В каталоге `TimeTransport/` находятся:

- `TimeTransport/` — общий интерфейс, модели, сервисы и данные.
- `TimeTransport.Desktop/` — запуск на Windows и Linux.
- `TimeTransport.Android/` — Android-приложение и ресурсы иконок.
- `TimeTransport.iOS/` и `TimeTransport.Browser/` — проекты для iOS и браузера.

## Запуск Desktop

Из каталога с этим README, при установленном .NET 10 SDK:

```bash
dotnet run --project TimeTransport/TimeTransport.Desktop/TimeTransport.Desktop.csproj
```

Для Android дополнительно нужны рабочая нагрузка .NET Android, Android SDK и JDK.
